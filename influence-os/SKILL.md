# influence-os

One home for the general-purpose influence prompt. `belief-patterns` holds the persuasion structures for Joe's own content and obeys Joe's copy laws. This skill holds the portable version: an operating prompt Joe can paste into any AI so it reasons the way Eli Wilde's system reasons, in any domain, with the guard rails that stop a sales technique from being used on a spouse.

## How to use it

1. Copy everything under the horizontal rule in `master-prompt.md` into the AI's system prompt, custom instructions or project instructions. For a Custom GPT, upload the master as a knowledge file and paste `gpt-loader.md` as the instructions.
2. Open with the situation, not the question. The prompt runs a context intake first (domain, power, state, consent, channel) and will ask one question at a time until it has enough.
3. Expect the output shape: context read, the belief as fact plus meaning, the leaking trust with evidence, the move, sayable lines, the risk in this context, one next action.

## What it refuses

The same list as `belief-patterns/references/refused.md`: manufactured urgency or scarcity, planting doubt, "naked and needy", embedded commands, identity boxing, invented proof. The prompt says so in one sentence and offers the trust-based alternative.

## Keeping it current

When the book itself becomes readable (see `references/sources.md`), a second pass adds Eli's seven metaphors, the 22 money techniques and the five transcribed conversations. Edit the master, keep the loader in sync, no dashes anywhere.
